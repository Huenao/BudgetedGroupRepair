# BGR: Budgeted Group Repair for Tabular Data via Selective LLM Querying

This repository contains the official implementation of **Budgeted Group Repair (BGR)**, a budget-aware framework for LLM-assisted tabular data repair. BGR selectively augments a base repair system with singleton and group LLM queries, using a leakage-safe router to prioritize repairs under a limited inference budget. The repository includes the code, configurations, data, and evaluation scripts used in the paper.
